# あれ売れた？

バザー・夏祭り・文化祭向けのイベント販売レジアプリです。

## 公開URL
https://takoyaki-project.github.io/are-ureta-event-register/

## できること
- 商品登録
- 在庫管理あり / レジのみ
- 売上記録
- 完売時間の記録
- 在庫調整
- おつり計算
- グループ別売上集計
- 引継ぎレポート作成
- PWA対応

## 想定利用シーン
- 学校バザー
- 夏祭り
- 文化祭
- PTAイベント
- 友の会バザー
- 小規模な販売会

## 注意
データは端末のブラウザ内に保存されます。
別端末とは自動共有されません。
イベント当日は同じ端末で使ってください。
